# 👥 User Management System

A simple and responsive User Management System built using React.js to manage user details efficiently.

## ✨ Features

- ➕ Add new users
- 👤 View user details
- ✏️ Edit user information
- 🗑️ Delete users
- 📱 Responsive user interface

## 🛠️ Technologies Used

- ⚛️ React.js
- 💛 JavaScript
- 🌐 HTML5
- 🎨 CSS3
- ⚡ Vite

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd user-management
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📌 Project Overview

This project demonstrates CRUD operations (Create, Read, Update, Delete) using React.js.
